# QDrop Photobooth Studio — ตัวติดตั้ง

ที่เก็บนี้มีไว้แจกจ่าย**ตัวติดตั้งและไฟล์อัปเดต**เท่านั้น ไม่มีซอร์สโค้ด

## ดาวน์โหลด

ไปที่ [Releases](../../releases) แล้วโหลดไฟล์ `QDrop.Photobooth.Studio.Setup.<รุ่น>.exe`

## ทำไมที่เก็บนี้ถึงเปิดสาธารณะ

ตัวโปรแกรมเช็ครุ่นใหม่ให้เองจากที่นี่ ถ้าปิดไว้ เครื่องของผู้ใช้จะต้องมี token
ถึงจะดาวน์โหลดตัวอัปเดตได้ ซึ่งเป็นไปไม่ได้ในทางปฏิบัติ

**ซอร์สโค้ดอยู่คนละที่และยังปิดอยู่**

## รุ่นทดสอบ

รุ่นที่ทำเครื่องหมาย pre-release ไว้ จะเห็นเฉพาะเครื่องที่เปิดช่องทดสอบในโปรแกรมแล้วเท่านั้น
เครื่องที่ใช้ทำงานจริงจะไม่ได้รับรุ่นเหล่านี้โดยไม่ตั้งใจ
